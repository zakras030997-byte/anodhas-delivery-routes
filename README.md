# Маршруты доставки

Локальная программа ANODHAS AI для диспетчера небольшого перевозчика. Городская развозка и междугородний рейс, загрузка машины после каждой остановки, расписание и плановые расходы.

## Яндекс.Карты в версии 1.1

Вкладка «Яндекс.Карты» открывает официальный бесплатный виджет внутри окна программы через системный WebKit. API-ключ не нужен. Введите «Откуда» и «Куда», при необходимости добавьте до 8 промежуточных остановок и нажмите «Построить маршрут». Можно поменять направление и взять точки выбранного рейса из локального плана. Адреса отправляются в Яндекс только после нажатия кнопки; контакты и стоимость заказов не передаются. Черновик адресов сохраняется на этом Mac отдельно для каждого плана.

Кнопка «Открыть в Яндекс.Картах» открывает полноценный официальный сайт в браузере для дополнительных настроек. Основное построение и изменение точек остаётся внутри программы. Виджет передаёт автомобильный маршрут `rtt=auto`; грузовой маршрут настраивайте и проверяйте на полном сайте Яндекса. Автоматический перенос параметров грузовика не заявляется. Встроенный переход на полный сайт в проверенной конфигурации WebKit не подтвердился, поэтому не используется как рабочая функция.

Расстояние, время и пробки виджета показывает Яндекс. Они не извлекаются из страницы и не подставляются в локальную экономику/расписание. Прежний расчёт в разделе «Маршруты» остаётся отдельной функцией VROOM/Valhalla. Это разные дорожные результаты. Сайт/виджет Яндекса требуют интернета, могут показывать рекламу и подчиняются условиям Яндекса; лицензия MIT распространяется на наш код.

Официальные источники: [бесплатный виджет](https://yandex.ru/dev/maps/mapstools/), [встраивание маршрута](https://yandex.ru/support/maps/ru/concept/get-map-reference), [веб-схема URL](https://yandex.ru/dev/yandex-apps-launch-maps/doc/ru/concepts/yandexmaps-web?from=mapstools), [параметры грузовика](https://yandex.ru/support/maps/ru/concept/rout-options).

## Работа

1. Создайте план, добавьте машину и заказы. Введите грузоподъёмность, объём, палеты, фактические габариты и массу машины.
2. Найдите адрес или введите координаты въезда. Подтвердите место и укажите часовой пояс. Временные окна содержат полную дату; можно требовать начала либо окончания обслуживания до закрытия.
3. В «Подключении» прочитайте условия открытого дорожного сервиса либо укажите собственный HTTPS Valhalla. Контакты и цены дорожному сервису не отправляются.
4. Рассчитайте порядок либо пересчитайте заданную последовательность. Выберите вариант для работы. После изменения заказов предыдущий расчёт помечается устаревшим.
5. Заполните расходы и выручку, сохраните маршрутный лист PDF/CSV или копию плана JSON.

Без подписки, Python, Docker и локальной дорожной базы. Нативный SwiftUI/AppKit, встроенный VROOM 1.15.0. Интернет нужен для поиска адресов, карты и дорожных запросов. Сохранённые планы и расчёты доступны локально.

## Что учитывается

- До 5 машин и 50 операций погрузки/выгрузки; междугородний рейс — одна машина.
- Вес, объём, палеты; парные операции «забрать и доставить», окна, обслуживание, смена, загрузка базы, введённые перерывы и требования к машине.
- Грузовые дорожные матрицы и фактическая геометрия Valhalla. После подбора порядка дорога запрашивается заново с массой на участке и временем выезда, а расписание проверяется независимо.
- Направления A→B и B→A считаются отдельно. Прямая линия не заменяет дорогу; отсутствие проезда или ответа не превращается в нулевой пробег.
- Топливо для гружёного и порожнего пробега, автомобиль, водитель, платные дороги, парковка, ночёвки, прочие расходы. Неизвестная статья остаётся неизвестной; выручка задаётся общей суммой либо по выполненным заказам.
- CSV/TSV и вставка из таблицы: предпросмотр, сопоставление колонок, ошибки до применения. Введённые адреса после импорта необходимо подтвердить.
- PDF/CSV выбранного маршрута; контакты по умолчанию не включаются. JSON переносит входные данные новой копией, требующей нового расчёта. Данные на этом Mac сохраняются отдельно от приложения.

## Дорожные данные и ограничения

По умолчанию используется официальный открытый Valhalla/FOSSGIS без ключа. Запросы ограничены приложением до одного за 1,15 секунды, автоматические повторы ограничены. Сервис сообщества может быть недоступен и не предоставляет гарантий. Матрица публичного сервиса ограничена расстоянием 150 км. Для дальних планов до 8 уникальных точек программа может запросить направленные маршруты отдельно; больший дальний план можно считать в заданном порядке по плечам либо подключить собственный совместимый сервис.

Живые пробки, подтверждение пропусков/прицепа, расчёт тарифов платных дорог и сертификация режима труда/отдыха не предоставляются. Введённые пропуска и прицеп сохраняются и обозначаются как требующие проверки. Полнота грузовых ограничений зависит от дорожных данных. Маршрут и безопасность остановок проверяет диспетчер.

Перед публичным распространением приложения с сервисом FOSSGIS нужно выполнить требования оператора и уведомить проект о предполагаемой нагрузке. Страница подробных условий оператора при исследовании была недоступна из-за Anubis; разрешение на массовое коммерческое использование этим исследованием не подтверждено. Для независимого выпуска предусмотрен свой Valhalla. Приложение не разворачивает сервер и не меняет VPN.

Карта/поиск адресов — Apple MapKit; дорожные данные — © OpenStreetMap contributors, Valhalla. Геокодер не определяет часовой пояс автоматически: его подтверждает пользователь.

## Сборка

Требуются Xcode Command Line Tools со Swift, C++20 и SDK, совместимым с компилятором; GNU make, git, Python 3 для проверок. Минимум macOS 13.3. ARM64 и x86_64 компилируются отдельно и объединяются в Universal.

```sh
export FREIGHT_SDK=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk
bash Scripts/build-solver.sh
bash Scripts/check.sh
bash Scripts/build.sh
bash Scripts/package.sh
```

VROOM зафиксирован на v1.15.0, commit `43dd7d0b8b560431eb555bf335cf4797eb7343c4`; сборка без сетевых библиотек, внешние матрицы передаются через JSON. Точная версия и notices входят в установку. `SIGN_IDENTITY` позволяет указать собственную подпись; без него создаётся локальная ad-hoc подпись. Developer ID/нотарификация требуют отдельной учётной записи владельца.

Проверки с локальными подменами не считаются подтверждением реального дорожного сервиса. `Tests/LiveVerification.swift --network` запускается отдельно и обращается к публичным координатам: Петербург и Москва. Отчёты текущей разработки не публикуются вместе с пользовательскими данными.
